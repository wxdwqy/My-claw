【两大基础URL】

  接口一：/hs/  →  沪深股票（个股行情、公司信息、板块列表）
  接口二：/hz/  →  沪深指数（指数实时行情）

  完整格式：
    https://api.zhituapi.com/hs/xxx?token=YOUR_TOKEN
    https://api.zhituapi.com/hz/xxx?token=YOUR_TOKEN

====================================================================
一、/hs/ 接口 —— 沪深股票
====================================================================

1. 个股实时行情
   GET /hs/real/ssjy/{代码}
   示例：https://api.zhituapi.com/hs/real/ssjy/600519?token=xxx
   支持：5195只A股（代码格式不含后缀，如 600519、000001、300750）
   返回字段：
     p     = 当前价格
     pc    = 涨跌幅（%）
     v     = 成交量（万手）
     cje   = 成交额
     pe    = 市盈率
     sz    = 总市值
     lb    = 量比
     hs    = 换手率

2. 公司基本信息
   GET /hs/gs/gsjj/{代码}
   示例：https://api.zhituapi.com/hs/gs/gsjj/600519?token=xxx
   返回：公司名称、行业、主营业务、总股本、流通股本等

3. 全市场股票列表
   GET /hs/list/all
   返回：5195只股票，每条含 dm=代码、mc=名称、jys=交易所

4. 概念板块列表
   GET /hs/list/sectors
   返回：2221个概念板块，每条含 dm=代码、mc=名称

--------------------------------------------------------------------
注意：以下/hs/接口免费版不可用
   /hs/public/ssjymore   批量查询（需付费）
   ETF相关接口           不在股票列表，免费版不支持
====================================================================
二、/hz/ 接口 —— 沪深指数
====================================================================

1. 指数列表
   GET /hz/list/hszs
   返回：611个指数（免费版可查代码列表）

2. 指数实时行情 ← 核心接口，早报主数据源
   GET /hz/real/ssjy/{指数代码}
   代码格式：带后缀，如 000001.SH、399001.SZ
   示例：https://api.zhituapi.com/hz/real/ssjy/000001.SH?token=xxx
   返回字段：
     p     = 当前价格（点位）
     pc    = 涨跌幅（%）
     cje   = 成交额
     v     = 成交量

   已验证可用的A股指数代码：
     000001.SH  上证指数
     399001.SZ  深证成指
     399006.SZ  创业板指
     000688.SH  科创50
     000300.SH  沪深300
     000016.SH  上证50
     000905.SH  中证500
     000852.SH  中证1000

--------------------------------------------------------------------
注意：以下/hz/接口免费版不可用
   /hz/latest/fhqy/{指数代码}  指数分时行情（需付费）

三、Python调用示例
====================================================================

import requests

TOKEN = "4BDA45E5-F103-4FE4-8C91-530D44F68C67"

# 查个股（600519 贵州茅台）
url = f"https://api.zhituapi.com/hs/real/ssjy/600519"
r = requests.get(url, params={"token": TOKEN}, timeout=5)
data = r.json()
print(f"茅台：{data.get('p')} | 涨跌：{data.get('pc')}%")

# 查指数（上证指数）
url = f"https://api.zhituapi.com/hz/real/ssjy/000001.SH"
r = requests.get(url, params={"token": TOKEN}, timeout=5)
data = r.json()
print(f"上证：{data.get('p')} | 涨跌：{data.get('pc')}%")
