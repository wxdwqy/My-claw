# 远程 IM 对话清理技能

## 目的

本技能用于清理 WorkBuddy 桌面客户端界面上的历史对话记录，特别是来自远程 IM 平台（飞书、QQ、微信、钉钉等）的消息，让用户界面保持清清爽爽。

## 何时使用

当用户表达以下意图时，使用本技能：
- "清理一下界面"
- "清空对话历史"
- "界面太乱了"
- "把之前的消息清掉"
- "清爽模式"
- "清理飞书/QQ/微信消息"

## 清理工作流程

### 1. 清空当前对话

使用 `/clear` 命令清空当前会话的所有对话历史：

```
/clear
```

这会清空当前窗口的所有消息记录，让界面焕然一新。

### 2. 管理会话列表

如果需要查看或切换到其他会话：

- 查看所有会话：`/resume list`
- 切换到指定会话：`/resume <session-id>`
- 删除不需要的会话：在 `/resume list` 显示的列表中管理

### 3. 重命名当前会话（可选）

如果当前会话名称混乱，可以重命名：

```
/rename 新会话名称
```

建议使用简洁的名称，比如"飞书对话"、"工作助手"等。

### 4. 检查连接器状态（可选）

如果用户关心 IM 平台的连接状态，可以告知当前状态：

- 所有 IM 连接器默认是断开状态
- 界面上不会显示来自这些平台的消息
- 如需连接，用户需要主动配置连接器

## 注意事项

1. **清理范围**：本技能只能清理 WorkBuddy 界面上的对话，**无法删除**用户手机或电脑上飞书/QQ/微信等应用中的实际消息记录。

2. **清理效果**：
   - ✅ 清空 WorkBuddy 对话窗口
   - ✅ 整理会话列表
   - ❌ 无法清理手机 IM 应用消息
   - ❌ 无法清理 IM 平台服务器上的消息

3. **用户体验**：清理后，界面会变得清清爽爽，适合继续新的对话任务。

## 示例对话

**用户**："好爪爪，帮我清理一下界面，太乱了"

**回复**：
```

- 查看其他会话：输入 /resume list
- 重命名当前会话：输入 /rename 新名称
```

## 技能限制

- 只能操作 WorkBuddy 界面，无法访问用户的 IM 应用（飞书、QQ、微信等）
- 无法删除 IM 平台服务器上的消息记录
- 清理操作仅影响当前 WorkBuddy 会话的显示

## 后续改进

- 添加自动备份对话历史的功能
