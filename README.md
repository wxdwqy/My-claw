## 技能列表

### 已上传技能

| 技能名 | 描述 | 状态 |
|--------|------|------|
| `opencli-browser-automation` | 基于 OpenCLI 的浏览器自动化，支持136个网站 | ✅ 已上传 |
| `tavily` | Tavily 搜索 API 集成 | 🚧 待上传 |
| `physics-animation-workflow` | 物理题动画生成工作流 | 🚧 待上传 |
| `bitmap-vectorize` | 位图转矢量图 | 🚧 待上传 |
| `ps-automation-2020` | PowerShell 自动化脚本 | 🚧 待上传 |
| `remote-im-cleaner` | 远程 IM 清理工具 | 🚧 待上传 |

### 使用前提

这些技能是为 **CodeBuddy / WorkBuddy** 设计的，需要：
- CodeBuddy AI 助手
- `~/.workbuddy/skills/` 目录

安装方法：
```bash
# 下载技能到本地 skills 目录
cp -r opencli-browser-automation ~/.workbuddy/skills/
```
